# Monic Font Assets Directory

Place your Monic font files in this directory (`frontend/public/fonts/`).

Supported formats & naming:
- `Monic.woff2` / `Monic.woff` / `Monic.ttf` / `Monic.otf` (Standard / Variable)
- `Monic-Light.woff2` / `Monic-Light.ttf` (Weight 300)
- `Monic-Regular.woff2` / `Monic-Regular.ttf` (Weight 400)
- `Monic-Medium.woff2` / `Monic-Medium.ttf` (Weight 500)
- `Monic-SemiBold.woff2` / `Monic-SemiBold.ttf` (Weight 600)
- `Monic-Bold.woff2` / `Monic-Bold.ttf` (Weight 700)

The site will automatically load Monic globally with seamless fallbacks.
